# Eka 0.1.1

Eka 0.1.1 completes the first reproducible ranking-benchmark phase. It adds a
deterministic, independently validated path for the reported system-disjoint
subgroup, system-concentration and 20,000-iteration stability diagnostics, with
synthetic corruption tests and locally hashed evidence.

The release also includes the source-release checklist, deployed Documenter
manual, expanded CI matrix, package-quality checks and explicit 0.1.x API
stability contract added since 0.1.0.

This is a **reproducible ranking benchmark**, not a validated discovery model.
It reconstructs withheld provenance labels from one contemporaneous Materials
Project snapshot; it does not establish chronological discovery performance,
synthesis success or generalization to unseen chemical systems. The frozen
2,000-iteration result remains primary and the 20,000-iteration run is post-hoc
stability characterization.

This tag is source-only. Record-level MP data, rankings, factors and environments
remain excluded; the optional evidence bundle was not approved or published.
