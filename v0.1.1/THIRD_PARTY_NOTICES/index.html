Seko recommender examples

Eight composition/score pairs in test/fixtures/build_fixture.jl and test/fixtures/tiny_test.db match examples in the sekocha/recommender README:

CompositionScore
Al2Ba2O7Si10.74232
Al2O12Si3Zn30.48140
Al1Li1O12Si50.41613
Al2Ba3O14Si40.39355
Al2O14Si4Sr30.34611
Zn1Mg30.39168
Zn1Mg20.37147
Mg1Zn40.26386

Some of these pairs also occur in README output, examples/scored_compositions.tsv, src/precompile.jl, and the CLI, database and legacy-schema tests. These pairs are upstream examples reused for software checks, not invented Eka predictions. The other four rows in the tiny fixture are project-authored test cases. docs/production-validation.md separately records observations from querying the upstream database; it is not evidence of predictions generated by Eka.
