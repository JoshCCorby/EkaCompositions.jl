Source release readiness

Reviewed 31 August 2026. This gate covers a source archive generated by git archive; it does not cover a local evidence directory, MP snapshot, candidate-level ranking bundle, dependency environment or production Seko database.

Candidate contents

The source candidate contains Eka's Julia and Python source, methodological documentation, synthetic examples, tests, the small noticed Seko-derived fixture, aggregate prose findings, MIT licence, third-party notices and citation metadata. Git archive attributes exclude local activity logs. Ignored local data and evidence directories are not members of the archive.

The aggregate findings identify Materials Project as the data source, database version 2026.04.13, retrieval time, transformations, GNoME exclusion, citation and non-endorsement limitation. No material IDs, candidate-level rankings, factors, MP snapshots, API keys or complete dependency environments are included.

Automated gate

Run from the repository root against the exact commit intended for release:

python scripts/verify_release.py --archive HEAD --output /tmp/eka-release-audit.json

The audit builds the actual Git archive and fails on:

  • local data, report or activity-log paths;
  • unreviewed JSONL/SQLite/database files, except the documented tiny fixture;
  • environment files and Manifest.toml;
  • symbolic links, hard links and other special archive members;
  • private-key markers and common GitHub, AWS and literal MP API-key forms;
  • machine-specific home paths, files over the review limit, missing licence, notice/citation metadata, or absent MP/Seko attribution.

The JSON output records every regular archive member's type, mode, size and SHA-256 plus a manifest hash. It is a content-control aid, not a guarantee that arbitrary secrets or all legal issues can be recognized automatically. CI runs the audit and its focused tests on every push and pull request.

Terms and decision

The terms evidence now includes a read-only check of the live official MP page on 31 August 2026. That page confirms CC BY 4.0 for MP Content with credit, licence link and change indication, and separately assigns GNoME CC BY-NC 4.0. The project excluded GNoME. MP asks users to contact it for guidance before repackaging and publicly redistributing MP data.

The source-only archive is ready as a release candidate because it does not repackage record-level MP data and retains the relevant attribution and notices. No tag, GitHub release or data publication is performed by this review. A future MP data/results bundle must receive a separate file-by-file review and may warrant provider guidance based on its concrete contents.
