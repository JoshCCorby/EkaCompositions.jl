Getting started

Installation

EkaCompositions supports Julia 1.10 and newer. From a repository checkout:

julia --project=. -e 'using Pkg; Pkg.instantiate(); Pkg.precompile()'

The package requires no network access after installation. Queries, tests and the synthetic examples all run offline.

Compositions

A Composition is a canonical reduced element ratio. Parsing normalises element order and divides out any common factor, so equality and hashing ignore both:

using EkaCompositions

composition = Composition("Zn1Mg2")
formula(composition)
"Mg2Zn1"
composition == Composition("Mg2Zn1")
true
Composition("Mg2Zn2") == Composition("MgZn")
true

That normalisation is load-bearing for callers using compositions as dictionary keys, and it will not change during 0.1.x:

length(Set([Composition("MgZn"), Composition("Zn2Mg2")]))
1

Formulas use valid element symbols and positive integer amounts. Repeated symbols are combined and counts reduce to the simplest ratio. Parentheses, isotopes, charges, whitespace and fractional amounts are unsupported.

Querying a score database

query_compositions is a read-only query over an existing SQLite score database. The examples below use the twelve-row fixture that ships with the repository for software testing — it is not a set of predictions.

fixture = joinpath(pkgdir(EkaCompositions), "test", "fixtures", "tiny_test.db")

results = query_compositions(fixture; elements=["Al", "Si", "O"], nary=[4], threshold=0.3)

for (composition, score) in results
    println(formula(composition), " => ", score)
end
Al2Ba2O7Si1 => 0.74232
Al2O12Si3Zn3 => 0.4814
Al1Li1O12Si5 => 0.41613
Al2Ba3O14Si4 => 0.39355
Al2O14Si4Sr3 => 0.34611

Inspect a database's schema with database_info, and audit every record in it with validate_database.

Command line

The eka executable in bin/ exposes the same query path plus six subcommands. Running it with no subcommand performs a stored-score query:

julia --project=. bin/eka -e Al Si O -n 4 -d test/fixtures/tiny_test.db
# Composition, Score
Al2Ba2O7Si1   0.74232
Al2O12Si3Zn3   0.48140
Al1Li1O12Si5   0.41613
Al2Ba3O14Si4   0.39355
Al2O14Si4Sr3   0.34611
CommandPurposeGuide
eka -d PATH [options]Query and rank stored SQLite scores.Production validation
eka importBuild a new query database from scored TSV records.Design notes
eka validateAudit every record in a SQLite database.Production validation
eka benchmarkEvaluate binary-labelled rankings at fixed budgets.Benchmark contract
eka audit-mpVerify and group an MP-shaped snapshot.MP pilot
eka split-mpGenerate deterministic PU splits.Split guide
eka benchmark-puVerify splits and evaluate PU methods.PU evaluation

Append --help to any subcommand. A bare --help describes the query options.

The command-line surface is frozen for 0.1.x: the same arguments produce the same results and the same output format. The Julia functions behind it are not equally stable — see API stability.
